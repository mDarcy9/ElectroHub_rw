# Project Title

## ElectroHub.rw – Online Electronics Store

---

# Project Objective

The purpose of this project was to design and develop a simple e-commerce website using Wix, a No-Code platform. The project demonstrates the practical application of e-commerce website design principles, user experience concepts, and GitHub Markdown documentation.

---

# Platform Used

- Wix Website Builder

---

# Project Description

ElectroHub.rw is an online electronics store developed using Wix. The website provides customers with a simple and user-friendly platform for browsing electronic products, viewing product details, learning about the business, and contacting customer support.

The platform was designed to offer a smooth navigation experience while implementing the fundamental features of an e-commerce website.

---
